# 📚 СРС Генератор

**Физика жана Электроника предметтери боюнча автоматтык СРС жасоочу программа**

Flutter менен жасалган, Gemini AI (бекер) колдонот.

---

## 🚀 Орнотуу жана иштетүү

### Талаптар
- Flutter 3.x орнотулган болушу керек
- Gemini API Key (бекер): https://aistudio.google.com/app/apikey

### Иштетүү
```bash
# 1. Бул папкага кир
cd srs_generator

# 2. Зависимостьтарды жүктө
flutter pub get

# 3. Windows үчүн иштет
flutter run -d windows

# же Android үчүн
flutter run -d android

# же APK жасоо
flutter build apk --release
```

1. **Предмет тандо**: Физика ⚡ же Электроника 🔌

## 🔑 Gemini API Key алуу (БЕКЕР)

1. https://aistudio.google.com/app/apikey сайтына кир
